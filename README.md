# sleeperattack.com

A plain-language reference page defining **sleeper attack** — a
*plant-persist-trigger* compromise of an LLM agent: a malicious instruction is
written into the agent's long-term memory, lies dormant to evade detection, and
later activates on a chosen condition.

**Live site:** https://sleeperattack.com

The page covers the definition, the plant-persist-trigger lifecycle, why it is
hard to catch, how it differs from Anthropic's "sleeper agents," and links to
the primary research (arXiv).

**Related attack class:** [skill injection](https://skillinjection.com) — a
malicious agent skill file that smuggles hidden instructions into an LLM agent.
